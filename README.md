# NewBeeMaker 新蜂创客

**十分钟，从新手到牛人。/ Bee a Maker.**

新蜂创客（NewBeeMaker）是芯步（ThingBoot）出品的创客开发工具：用 Python 玩转 ESP32 开发板，
本地模拟、一键部署、云端控制，10 分钟点亮你的第一颗 LED。

## 下载

👉 [Releases 页面](https://github.com/NewBeeMaker/maker/releases) 获取最新安装包。

| 平台 | 要求 |
|---|---|
| Windows | Windows 10 22H2 x64 及以上 / Windows 11 |
| macOS | 13+（Apple Silicon 优先，Intel 实验性） |

## 特性

- **Python 编程硬件**：`from machine import Pin`，会 Python 就会玩硬件
- **本地模拟**：不插板子也能先跑起来调试
- **一键部署**：脚本打包下发，失败可手动回滚，崩溃自动进安全模式
- **云端控制**：注册 `on_order` 回调，从云端命令控制你的板子
- **蜂巢社区**（即将上线）：分享作品——代码、接线图、物料单一站打包，一键导入复刻别人的创意
